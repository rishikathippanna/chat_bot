# 🎓 College FAQ Chatbot using RAG

A Domain-Specific College FAQ Chatbot built using Python, FAISS, Sentence Transformers, and Retrieval-Augmented Generation (RAG).

The chatbot answers college-related questions such as:
- Admissions
- Courses
- Hostel Facilities
- Fee Structure
- College Timings
- Contact Information

---

# 🚀 Features

- Semantic search using Sentence Transformers
- Fast retrieval using FAISS Vector Database
- College FAQ dataset support
- Human-like conversational responses
- Simple command-line chatbot
- Retrieval-Augmented Generation (RAG) architecture

# 💬 Example Queries

```text
What courses are offered?
Is there a hostel facility?
What is the fee structure?
How can I apply for admission?
```

---

# 🧠 How It Works

1. User enters a query
2. Sentence Transformer converts query into embeddings
3. FAISS retrieves most relevant FAQ
4. Chatbot displays matching response
